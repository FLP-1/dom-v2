## 🚀 **Como testar AGORA:**

### **Opção 1: Teste no Navegador (MAIS RÁPIDO)**
```powershell
cd DOMv2Android
npx expo start --web
```

### **Opção 2: Teste no Emulador Android**
```powershell
cd DOMv2Android
npx expo start
# Depois pressione 'a' para abrir no Android
```

### **Opção 3: Teste no Celular**
```powershell
cd DOMv2Android
npx expo start
# Escaneie o QR code com o app Expo Go
```

### **Opção 4: Teste com Android Studio**
```powershell
cd DOMv2Android
npx expo run:android
```
