## 🚀 **Guia de Uso Completo**

### **Instalação e Configuração**

```bash
# Clonar o repositório
git clone <repository-url>
cd dom-v2

# Instalar dependências
npm install

# Configurar variáveis de ambiente
cp .env.example .env
# Editar .env com suas configurações
```

### **Execução das Fases**

```bash
# Fase 9: Interface Web
npm run phase9-web-interface

# Fase 10: Monitoramento Inteligente
npm run phase10-intelligent-monitoring

# Fase 11: Automação Total e IA
npm run phase11-total-automation-ai

# Fase 12: IA Generativa
npm run phase12-generative-ai

# Fase 13: Orquestração Total
npm run phase13-total-orchestration

# Fase 14: IA Cognitiva Avançada
npm run phase14-advanced-cognitive-ai
```

### **Acesso às Interfaces**

- **Interface Web**: http://localhost:3000
- **API REST**: http://localhost:3000/api
- **Métricas**: http://localhost:3000/api/metrics
- **Controles**: http://localhost:3000/controls
